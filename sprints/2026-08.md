## The four questions

Answerable only by watching. Record answers in the review.

| # | Question | Why it matters |
|---|---|---|
| 1 | Does a navigating enemy feel smarter — or just slower? | The real risk. Deliberate reads as hesitant, and hesitant is worse than dumb |
| 2 | Should an agent ever fail a jump? | Perfect traversal reads robotic; a missed ledge reads alive. Cheap to allow, hard to retrofit |
| 3 | Should the player break pursuit using terrain? | Determines how memory and repathing work |
| 4 | Is a committed route readable? | Visible intent can be outplayed; continuous repathing cannot |

### Behavior Lab v2 — locked scope

Replaces `src/editor/tools/behavior-lab.js` entirely.

- A randomly generated level
- One agent
- Click anywhere to set that point as its goal
- Watch it get there
- Nav graph and current route as overlays

Nothing else. No combat, no teams, no rosters, no scoreboards, no levers. Being
quick to build is not a reason to add anything. Model on `firing-room.js`.
